# Code de conduite

Dans le but de favoriser un environnement accueillant et constructif, tous les participants s'engagent
à respecter les uns les autres.

## Nos valeurs

- **Respect** : écouter, construire sur les idées des autres, rejeter tout comportement exclusif ou
  agressif.
- **Transparence** : expliquer ses décisions, signaler les problèmes ouvertement.
- **Construction** : critiquer les idées, pas les personnes.
- **Responsabilité** : reconnaître ses erreurs et s'améliorer.

## Ce qui n'est pas acceptable

Comportements abusifs, harcelants, discriminants ou destructeurs. Ils ne seront pas tolérés.

## Application

Les membres de l'équipe s'engagent à corriger et investiguer tout comportement inacceptable selon
une procédure transparente.

## Signaler un problème

Contacter un mainteneur de projet pour remonter un comportement problématique.
